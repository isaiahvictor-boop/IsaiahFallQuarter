1. What is Git, what is Github, and what is the difference between the two? git is a version control system that tracks files, and github is the website to help you use it.
2. What is the difference between a local repository and a remote repository? The difference between a local and remote repository is the local one only saves to that device and the remote saves to a external place.
3. What does the push command do in Git? it uploads changes from your local repo to the remote repo.
4. What does the commit command do in Git? it acts as a save button for your local repo.
5. What is Github Desktop, & why are we using it? Github desktop lets you use git and github without having to type out all the code.
